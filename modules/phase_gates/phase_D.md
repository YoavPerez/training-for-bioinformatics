# Phase gate D — Production & research (modules 7–8)

Closed-book, 45 minutes. Score yourself with `phase_D_answers.md`.

**PD-01.** List what must be pinned so that a pipeline run can be reproduced a year later.

**PD-02.** Your Argo fan-out over 30 sequences finishes in the same time as over 3. What do you look at?

**PD-03.** How do Argo steps pass a metrics file to a summary step?

**PD-04.** A regression gate failed on a PR that only changed documentation. Name two possible causes.

**PD-05.** How do you choose the tolerance of a regression gate?

**PD-06.** What is the difference between a unit test and a regression benchmark, and why do you need both?

**PD-07.** Where in a tech report do the commit hash, config and dataset version belong?

**PD-08.** What makes a hypothesis falsifiable? Give one for "voxel size vs drift".

**PD-09.** Your effect is 3 % with a CI of ±5 %. What is the correct conclusion?

**PD-10.** Name three of Peyton Jones's seven suggestions.

**PD-11.** What is a scope cut, and when do you decide it?

**PD-12.** Bridge: experiment tracking in this program and in a bioinformatics pipeline (e.g. a variant-calling workflow): what are the equivalents of the drive id, the `prepare` seed and the commit hash?
